# Fullstack Healthcare

Fullstack Healthcare is a modern healthcare management web application built with Next.js, TypeScript, Prisma, Clerk Authentication, and Tailwind CSS.

It is designed to help clinics and hospitals manage patients, doctors, appointments, medical records, billing, and administrative workflows in a single platform.

## Features

- Patient management
- Doctor and staff management
- Appointment booking and tracking
- Medical history and medical records
- Billing and payment flow
- Admin dashboard and insights
- Authentication and user management with Clerk

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Prisma ORM
- PostgreSQL
- Clerk Authentication
- Tailwind CSS
- shadcn/ui
